A system that record, validate, track, and analyze student violation/admission-slip cases in one place.

Core features:

Secure user authentication and account recovery (login, forgot password, change password, security question).
Digital admission slip/form workflow for creating and completing case records.
Violation-description validation (with local LLM support + fallback matching) to improve record consistency.
Search and retrieval of past records for quick case follow-up.
Dashboard and analytics/visualizations for trends, counts, and behavior patterns.
Printable admission slips for documentation and reporting.
Backend protections like rate limiting and input validation for safer, more reliable use.
Problems it solves:

Replaces scattered/manual discipline logs with a centralized system.
Reduces inconsistent or unclear violation tagging through validation rules.
Speeds up case handling by making records searchable and easy to update.
Improves decision-making with data insights instead of guesswork.
Supports accountability and audit readiness through structured, printable records.
Lowers operational friction for counselors, advisers, and administrators.
